# Naina — A Little World Made For You · V5

A premium static birthday quest for Naina.

## V5 update
- Restored the original **photo-unlock experience**.
- Added 8 real user-provided photos as `assets/memory-1.jpg` through `assets/memory-8.jpg`.
- Photos unlock sequentially and open in a cinematic full-size memory modal.
- Photo mapping:
  1. `bchpan` — childhood
  2. `behn` — sister + dog
  3. dance photo — energy/fun
  4. yellow sweater — cute moment
  5. peacock photo — quiet/soft moment
  6. sister selfie — people/family
  7. sunglasses — playful side
  8. elegant outfit — present/future chapter
- The dog photo is reused in the hidden-heart mini-game.
- One supplied photo is used in the music chapter and the final surprise.
- V5 uses a separate localStorage key: `nainaQuestV5`.
